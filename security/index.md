# Security Policy

**Last updated: September 23, 2026**

Kreuter Apps is operated by V5 Joining Technologies. This Security Policy describes security practices for our Atlassian Marketplace applications, including Project Budget Guard.

## Project Budget Guard

Project Budget Guard is built on the Atlassian Forge platform and operates within Atlassian-hosted infrastructure.

### Data storage

Project Budget Guard stores project configuration data using Atlassian Forge-hosted storage.

The app does not use an external application server or database to store Jira project data, worklogs, or Project Budget Guard configuration data.

### Data access

Project Budget Guard accesses Jira project information and worklog data through Atlassian APIs as necessary to calculate project labor hours and costs.

Access is limited to the permissions required for the app's functionality.

### External data transfer

Project Budget Guard does not send Jira project data, worklog data, or stored Project Budget Guard configuration data to external services.

The app does not use external analytics, advertising, or marketing services to process customer data.

### Credentials

Project Budget Guard does not require customers to provide Atlassian passwords, Personal Access Tokens, API tokens, or other shared credentials.

### Data residency

Project Budget Guard uses Atlassian Forge-hosted storage. In-scope Project Budget Guard configuration data follows the data residency capabilities provided by the Atlassian Forge platform.
