# Privacy Policy

**Last updated: September 23, 2026**

Kreuter Apps is operated by V5 Joining Technologies ("we," "us," or "our"). This Privacy Policy describes how information is handled by our Atlassian Marketplace applications, including Project Budget Guard.

## Project Budget Guard

Project Budget Guard operates within the Atlassian Forge platform and helps Jira users monitor project labor costs, budgets, and projected costs.

### Information the app accesses

Project Budget Guard accesses Jira project information and worklog data as necessary to calculate project labor hours and costs.

The app also stores configuration information entered by users for each Jira project, including:

- Project budget
- Hourly labor cost
- Budget warning threshold
- Estimated project completion percentage
- Selected currency

### Personal data

Project Budget Guard does not copy or store Jira user profile information or other user-referenced personal data in an external system.

The app does not require users to create a separate Kreuter Apps account.

### Data storage and processing

Project Budget Guard is built on Atlassian Forge. App configuration data is stored using Atlassian Forge-hosted storage.

Project Budget Guard does not use an external application server or database to process or store Jira project data.

### Third-party sharing

We do not sell Project Budget Guard customer data.

Project Budget Guard does not send Jira project or worklog data to third-party services for advertising, analytics, or marketing purposes.

### Data retention

Project configuration information is retained in Atlassian Forge-hosted storage as needed to provide the app's functionality.

### Security

Project Budget Guard uses Atlassian Forge infrastructure and APIs to provide its functionality. Access to Jira data is limited to the permissions required by the app.

### Changes to this policy

We may update this Privacy Policy as our applications or legal requirements change. Updates will be posted on this page with a revised "Last updated" date.
